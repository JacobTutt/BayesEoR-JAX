    Setup¶

    A run is described by a RunConfig, normally read from YAML by BayesEoRParser. run_setup then loads the data, builds or reuses the operators, and returns a SetupResult holding everything the sampler needs.

    from bayeseor_jax import BayesEoRParser, run_setup

config = BayesEoRParser().parse_args(["--config", "config.yaml"])
setup = run_setup(config)

    See construction and execution for what setup does. Each setting is documented on the guide page it affects, and the examples show complete, commented configurations.

    Main interface¶

    bayeseor_jax.setup.run_setup ¶

    run_setup(config: RunConfig, *, build_foreground_kl: bool = False, kl_f: float = 0.1) -> SetupResult

    Prepare the physical operators, priors and marginalised likelihood.

    Parameters:

    Name Type Description Default
    config RunConfig

    Requested data/model/inference settings. Actual observation axes and model coordinates are resolved locally without modifying this object.

    		 required
    build_foreground_kl bool

    Construct the weighted foreground operator and reduce it into config.foreground_kl_path before joint assembly. Rebuilds the basis when explicitly requested; otherwise loads the supplied basis unchanged.

    		 False
    kl_f float

    Maximum discarded foreground RMS relative to the noise when building the KL basis. Defaults to 0.1; ignored when loading an existing basis.

    		 0.1

    Returns:

    Type Description
    SetupResult

    Configured likelihood, coefficient and power-spectrum priors, matrix builder, selected visibility data and cosmological bin metadata.
    Notes

    This coordinates loading, geometry, component construction, joint assembly and likelihood products; it does not run nested sampling. KL construction uses the resolved observation, physical prior and inference noise weights. A supplied KL operator is loaded with a standard-normal prior, and is only recomputed when build_foreground_kl is explicitly enabled. Omitted image and transverse Fourier resolutions are inferred from the selected observation. Explicit values below the estimates trigger warnings but are retained; these checks do not replace convergence studies.

    		 ()

    		 ()
    parse_as_dict bool

    Return a plain dictionary instead of RunConfig when explicitly enabled. The standard workflow uses the typed result directly in run_setup.

    		 False

    YAML keys use underscores and CLI flags use dashes. The options retain their existing names and required fields. The CLI output directory keeps its historical ./BayesEoROutputs/ default; direct RunConfig construction retains the Python setup default ./.

    Configuration objects¶

    RunConfig holds every setting, and ModelConfig the subset that defines the physical operators. Both are frozen dataclasses: use dataclasses.replace to derive a new configuration.
