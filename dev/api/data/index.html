    Data¶

    get_vis_data loads a visibility file or preprocessed vector and returns the data vector, noise information and observation axes in the analysis convention. The instrument enters through its baselines, InstrumentModel, and its primary beam, Beam_Model.

    See the Data guide for the supported inputs and settings.

    bayeseor_jax.data.vis.preprocess_uvdata ¶

    preprocess_uvdata(filepath, antenna_selection='cross', bl_cutoff=None, freq_idx_min=None, freq_min=None, freq_center=None, n_freqs_select=None, jd_idx_min=None, jd_min=None, jd_center=None, n_times_select=None, form_pi=True, pi_norm=1.0, pol='xx', redundant_avg=False, uniform_redundancy=False, calc_noise=False, return_uvd=False, save_vis=False, save_model=False, save_dir='./', clobber=False)

    Read visibility data from disk and form a one-dimensional data vector.

    This function loads a pyuvdata-compatible file containing visibilities for a set of baselines (Nbls), times (Ntimes), and frequencies (Nfreqs) and forms a one-dimensional data vector with shape (2*Nbls * Ntimes * Nfreqs,) and an accompanying instrument model of baseline coordinates in metres and a redundancy model (when averaging redundant baselines). The factor of two comes from appending conjugate visibilities at reversed baselines (u, v, w) -> (-u, -v, -w). These are redundant copies of the measurements, not independent observations. Time is the slowest axis, frequency next, and baseline fastest.

    Optionally, if calc_noise is True, a noise vector is also produced. The noise is estimated by differencing visibilities at even and odd time steps per baseline and frequency.

    Parameters:

    Name Type Description Default
    filepath Path or str

    Path read by pyuvdata (normally UVH5, UVFITS or a Measurement Set). Unlike get_vis_data, this lower-level function delegates format detection directly to UVData.read. Input units must be Jy or K sr.

    		 required
    antenna_selection str

    Antenna downselect string. This determines what baselines to keep in the data vector. Please see pyuvdata.UVData.select for more details. Defaults to 'cross' (cross-correlation baselines only).

    		 'cross'
    bl_cutoff Quantity or float

    Cutoff on sqrt(u2 + v2), in metres if not a Quantity. Defaults to None (keep all baselines).

    		 None
    freq_idx_min int

    Minimum frequency channel index to keep in the data vector. Defaults to None (keep all frequencies).

    		 None
    freq_min Quantity or float

    Minimum frequency to keep in the data vector in Hertz if not a Quantity. All frequencies greater than or equal to freq_min will be kept, unless n_freqs_select is specified. Defaults to None (keep all frequencies).

    		 None
    freq_center Quantity or float

    Central frequency, in Hertz if not a Quantity, around which n_freqs_select frequencies will be kept in the data vector. n_freqs_select must also be passed, otherwise an error is raised. Defaults to None (keep all frequencies).

    		 None
    n_freqs_select int

    Number of frequencies to keep starting from freq_idx_min, the channel corresponding to freq_min, or around freq_center. Defaults to None (keep all frequencies).

    		 None
    jd_idx_min int

    Minimum time index to keep in the data vector. Defaults to None (keep all times).

    		 None
    jd_min Time or float

    Minimum time to keep in the data vector as a Julian date if not a Time. Defaults to None (keep all times).

    		 None
    jd_center Time or float

    Central time, as a Julian date if not a Time, around which n_times_select times will be kept in the data vector. n_times_select must also be passed, otherwise an error is raised. Defaults to None (keep all times).

    		 None
    n_times_select int

    Number of times to keep starting from jd_idx_min, the time corresponding to jd_min or around jd_center. Defaults to None (keep all times).

    		 None
    form_pi bool

    Form pseudo-Stokes I visibilities. Otherwise, use the polarization specified by pol. Defaults to True.

    		 True
    pi_norm float

    Normalization, N, used in forming pseudo-Stokes I from XX and YY via pI = N * (XX + YY). Defaults to 1.0.

    		 1.0
    pol str

    Case-insensitive polarization string. Used only if form_pi is False. Defaults to 'xx'.

    		 'xx'
    redundant_avg bool

    Redundantly average the data. Defaults to False.

    		 False
    uniform_redundancy bool

    Force the redundancy model to be uniform. Defaults to False.

    		 False
    calc_noise bool

    Calculate a noise estimate from the visibilities via differencing adjacent times per baseline and frequency. Defaults to False.

    		 False
    return_uvd bool

    Return the preprocessed UVData object. Defaults to False.

    		 False
    save_vis bool

    Write visibility vector to disk in save_dir. If calc_noise is True, also save the noise vector. Defaults to False.

    		 False
    save_model bool

    Write instrument model (antenna pairs, (u, v, w) sampling, and redundancy model) to disk in save_dir. Defaults to False.

    		 False
    save_dir Path or str

    Output directory if save_vis or save_model is True. Defaults to './'.

    		 './'
    clobber bool

    Clobber files on disk if they exist. Defaults to False.

    		 False

    Returns:

    Name Type Description
    vis ndarray

    Complex visibility vector in mK sr, shape (2NblsNfreqs*Ntimes,).
    antpairs list of tuple

    List of antenna pair tuples corresponding to the (u, v, w) coordinates in uvws, in identical order, with length (2*Nbls).
    uvws ndarray

    Baseline coordinates in metres, shape (Ntimes, 2*Nbls, 3). The ordering of the Nbls axis matches the ordering of the baselines in vis.
    redundancy ndarray

    Redundancy model containing the number of baselines averaged within a redundant baseline group, shape (Ntimes, 2*Nbls, 1).
    noise ndarray or None

    Estimated noise vector with shape (2NblsNfreqs*Ntimes,). Returned as None when calc_noise is False.
    uvd UVData or None

    Preprocessed UVData object. Returned only if return_uvd is True.
    Notes

    This path assumes a common set of baselines at every selected time and unprojected drift-scan geometry. Fully flagged baselines are removed, but individual flagged samples are not masked or assigned zero weight here. The returned UVData data array has been converted to mK sr; its original vis_units label is not updated. Use the returned vector for inference.

    bayeseor_jax.model.instrument.baselines.InstrumentModel ¶

    Load a BayesEoR instrument model.

    The instrument model consists of: - (u, v, w) array with shape (nt, nbls, 3) where nt is the number of times and nbls is the number of baselines - Number of redundantly-averaged baselines per (u, v, w) with shape (nt, nbls) or (nt, nbls, 1) - (optional) a list of antenna pair tuples with length nbls matching the order of baselines in the (u, v, w) array

    bayeseor_jax.model.instrument.beam.Beam_Model ¶

    Supply the beam weights multiplying image-domain sky brightness.

    Parameters:

    Name Type Description Default
    beam_type str

    Supported beam types are:

    • uniform: unit power response above the horizon (the default).
    • gaussian: Gaussian profile with a specified angular width or an aperture-derived, frequency-dependent width.
    • airy: Airy power pattern for a circular aperture.
    • gausscosine: Gaussian profile modulated by a cosine-squared response.
    • taperairy: Airy power pattern multiplied by a Gaussian taper.
    • tanhairy: Airy power pattern multiplied by a hyperbolic-tangent taper.
    • A beamfits file path: an arbitrary tabulated beam loaded through pyuvdata.UVBeam and interpolated onto the sky-pixel directions and observing frequencies. Both HEALPix and azimuth/zenith-angle beam grids are supported; pol selects the polarisation and freq_interp_kind selects the frequency interpolation method (cubic by default).
    		 None
    peak_amp float

    Peak power-response amplitude for Gaussian-based profiles. Defaults to 1.0; the uniform and untapered Airy profiles have unit peak.

    		 1.0
    fwhm_deg float

    Full width at half maximum in degrees. Gaussian-based profiles use this width when supplied, otherwise deriving a width from diam.

    		 None
    diam float

    Antenna (aperture) diameter in meters. Used if beam_type is 'airy'.

    		 None
    cosfreq float

    Cosine frequency in inverse radians. Used if beam_type is 'gausscosine'.

    		 None
    tanh_freq float

    Exponential frequency (rate parameter) in inverse radians. Used if beam_type is 'tanhairy'.

    		 None
    tanh_sl_red float

    Fractional suppression of the Airy power response far from zenith. Used if beam_type is 'tanhairy'.

    		 None
    pol str

    Polarization string. Used only if beam_type is a UVBeam file path. Defaults to 'xx'.

    		 'xx'
    freq_interp_kind str

    Frequency interpolation kind from scipy.interpolate.interp1d. Defaults to 'cubic'.

    		 'cubic'
    Notes

    Analytic profiles or an interpolated UVBeam power model are evaluated at each pixel's topocentric direction and observing frequency. get_beam_vals returns the diagonal entries of the primary-beam operator; it does not allocate a dense diagonal matrix.

    aperture_width_uv ¶

    aperture_width_uv(freqs_hz: ndarray, gaussian_nsigma: float = 5.0) -> float

    Estimate the transverse Fourier extent added by primary-beam weighting.

    Parameters:

    Name Type Description Default
    freqs_hz array - like

    One-dimensional observing-frequency array in Hz.

    		 required
    gaussian_nsigma float

    Number of Gaussian standard deviations used to define the beam support in uv space. Defaults to 5.

    		 5.0

    Returns:

    Type Description
    float

    Approximate beam-support width in uv units. Returns 0.0 for uniform beams and UVBeam file inputs, where no simple analytic aperture-width estimate is available.
    Notes

    This quantity supplies the buffer around measured baselines when choosing the cosmological uv grid. Airy-like beams contribute an aperture width equal to the effective dish diameter in wavelengths, while Gaussian-like beams contribute Nsigma / (2πσ) using the broadest angular width at the lowest observing frequency.

    The random draw intentionally follows the old BayesEoR NumPy implementation so the realized noise matches the original pipeline for the same sigma and random_seed:

    		 required
    bl_red_array Array

    		 required
    random_seed int or None

    Seed for deterministic noise generation.
