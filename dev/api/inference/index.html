    Inference¶

    MarginalisedLikelihood evaluates the marginalised likelihood for a set of power-spectrum amplitudes, and run_multinest samples it. MaximumAPosteriori recovers the conditional coefficients from the same products. All three are built from the SetupResult returned by run_setup.

    from bayeseor_jax import run_nestedsampling

summary = run_nestedsampling(setup, out_dir="outputs/multinest")
log_l = setup.likelihood_class.log_likelihood(rho)

    Sampling¶

    run_nestedsampling is an alias of run_multinest.

    bayeseor_jax.inference.run_ns.run_multinest ¶

    run_multinest(setup_result: SetupResult, out_dir: Path | str, *, random_key: int | None = None, n_live_points: int | None = None, n_live_scale_factor: float = 25.0, calc_avg_eval: bool = False, avg_iters: int = 10, file_root: str = 'data-', resume: bool | None = None, verbose: bool = False, importance_nested_sampling: bool | None = None, multimodal: bool | None = None, const_efficiency_mode: bool | None = None, evidence_tolerance: float | None = None, sampling_efficiency: float | None = None, max_iter: int | None = None, print_rate: int = 100) -> dict[str, Any]

    Run MultiNest, or evaluate a parameter-free model analytically.

    A model with no sampled hyperparameters needs no nested sampling. Its conditional MAP coefficients and marginalised log-evidence target are evaluated in one solve and saved as map_coefficients.npy and summary.json. The same fixed data/noise normalisation is omitted as in the sampled likelihood, so same-dataset model comparisons are unchanged.

    This implementation is intentionally single-process at the sampler level. The expensive operation is still the likelihood evaluation itself, which can use multiple GPUs internally through the JAXMg-backed marginalized likelihood.

    By default this wrapper mirrors the old BayesEoR MultiNest runner closely: aside from the required output basename and resolved live-point count, it leaves the remaining MultiNest options unset so the underlying pymultinest.solve defaults apply.

    The log likelihood at the prior midpoint is automatically subtracted before passing values to MultiNest. This avoids loss of precision in its evidence-error estimate for bright foregrounds. The offset is restored in the returned logZ and saved in summary.json; native MultiNest files retain centred values. Resuming requires the saved likelihood_offset.json and uses its recorded offset unchanged.

    Likelihood and MAP¶

    bayeseor_jax.inference.likelihood_marg.MarginalisedLikelihood ¶

    Configuration for marginalized log-likelihood evaluation.

    This class evaluates the analytically marginalized BayesEoR target from the compressed matrix stack

    T^H N^{-1} T, T^H N^{-1} d, and d^H N^{-1} d.

    Single-device inference uses a standard JAX Cholesky factorisation on CPU or GPU; multi-GPU inference uses JAXMG. Both evaluate the same Gaussian target. The large dense matrix is kept row-sharded over a 1D device mesh, while the right-hand side vector and scalar normalization term are replicated. Each likelihood call builds the diagonal prior precision Phi^{-1}, forms

    Sigma = T^H N^{-1} T + Phi^{-1}

    in a work matrix, and then uses one factorisation to obtain both Sigma^{-1} dbar and log|Sigma|.

    Visibilities contain both each measured value and its conjugate, as produced by uvd_to_vector. They are not independent complex samples: the Gaussian exponent and log determinants therefore carry factors of one half. Foreground image coefficients are real, and cosmological Fourier coefficients obey the real-sky conjugacy constraint. A reduced operator must preserve this covariance structure, not introduce independent complex sky amplitudes.

    The returned target omits fixed data/noise normalisation terms. These cancel in Bayes factors only when both models use the same dataset, noise covariance and omitted constants; see docs/inference.md.

    log_likelihood ¶

    log_likelihood(theta: Array) -> jax.Array

    Evaluate marginalized Gaussian log-likelihood.

    This integrates out the latent linear coefficient vector analytically, evaluates the resulting dense system on the stored CPU or GPU solver mesh, and returns the Hermitian-augmented Gaussian target with fixed normalisation terms omitted and optional intrinsic-noise and Jacobian corrections.

    bayeseor_jax.inference.maxaposteriori.MaximumAPosteriori ¶

    Conditional MAP solver for the latent linear coefficient vector.

    For fixed sampled parameters theta, this class constructs the dense Gaussian system

    Sigma = T^H N^{-1} T + Phi^{-1}

    and solves for the conditional MAP coefficients

    b_hat = Sigma^{-1} dbar

    with dbar = T^H N^{-1} d.

    The implementation uses the same compressed likelihood terms as the marginalized likelihood: T_Ninv_T, dbar, and d_ninv_d. The stored normal matrix is row-sharded over a 1D solver mesh, while the right-hand side and scalar normalization term are replicated. Each call builds the diagonal prior precision implied by theta and uses a JAX Cholesky factorisation on one CPU or GPU, or jaxmg.potrs across GPUs, to solve the system and return the MAP coefficient vector.
