    Construction and KL reduction¶

    These functions build full-size operators on CPU in time-frequency blocks, writing them to disk, and return the saved paths. Every participating process makes the same calls; see execution.

    Operators¶

    BuildMatrices prepares the physical inputs from a configuration and exposes the same writers as methods. The writers can also be called directly.

    bayeseor_jax.model.construction.model_builder.BuildMatrices ¶

    Parameters:

    Name Type Description Default
    config ModelConfig

    Requested spectral, beam and storage settings. A RunConfig is also accepted, but data-selection, prior and sampler fields are not used.

    		 required

    Resolved observing frequencies in Hz, shape (n_frequency,).

    		 required
    uvw_array_m array - like

    Resolved physical baselines, shape (n_time, n_baseline, 3), in metres. The first integration supplies the fixed instrument-frame baselines.

    		 required
    image_geometry ImageGeometry

    Prepared HEALPix pixel selections, time-dependent directions and areas. This fixes the actual image support; it is not rebuilt from config.

    		 None
    Notes

    Geometry is resolved before construction. This object prepares the beam, Fourier factors and foreground spectra once, then its component writers construct CPU blocks and save separate operators. Joint assembly, noise weighting, KL reduction and inference remain separate stages.

    T_fg_weighted_build_save ¶

    T_fg_weighted_build_save(*, prior_sqrt, noise_whitener, matrix_name: str = 'A_fg') -> Path

    Save the prior- and noise-weighted foreground operator directly on CPU.

    Parameters:

    Name Type Description Default
    prior_sqrt array - like

    Nonnegative prior standard deviations in spectral-component/pixel order, one per foreground coefficient.

    		 required
    noise_whitener array - like

    Positive inverse noise RMS in time/frequency/baseline order, one per visibility. Both weights must be finite real vectors.

    		 required
    matrix_name str

    Output file stem within array_save_directory; defaults to A_fg.

    		 'A_fg'

    Returns:

    Name Type Description
    path Path

    Complete complex128 A = N^-1/2 T_fg Sigma_q^1/2 operator for KL decomposition. No unweighted foreground file is required or saved.
    Notes

    Weights are explicit inputs, separate from physical model configuration. The shared CPU writer applies them within each time-frequency block; decomposition and truncation are not performed here.

    Distribute pure forward-operator evaluations and save their complete matrices.

    Each process writes disjoint visibility-row blocks to shared storage. Numerical evaluation stays in model.operators; this module owns CPU placement and file publication. Optional diagonal weights are applied by the pure weighted operator; KL decomposition and truncation remain separate stages.

    KL reduction¶

    T_fg_svd_build_save decomposes a prior- and noise-weighted operator, truncates it and saves the reduced basis.

    bayeseor_jax.model.construction.kl_reduction.T_fg_svd_build_save ¶

    T_fg_svd_build_save(weighted_operator_path, ninv_path, *, output_path, f=0.1, tile_size=128)

    Decompose and truncate A, then save T_fg,r = N^1/2 U_r S_r.

    Parameters:

    Name Type Description Default
    weighted_operator_path Path or str

    Saved complex128 matrix A = N^-1/2 T_fg Sigma_q^1/2, shape (n_visibility, n_foreground_coefficient), in time/frequency/baseline row order. Prior and noise weighting must already have been applied.

    		 required
    ninv_path Path or str

    Saved positive diagonal inverse noise E[|n_i|^2]^-1, shape (n_visibility,). Must be the same diagonal noise used to construct A. Correlated-noise whitening is not supported by this saved-file routine.

    		 required
    output_path Path or str

    Shared destination, normally T_fg_reduced.npy. Also saves singular values to .singular_values.npy and diagnostics to .svd.json.

    		 required
    f float

    Maximum discarded RMS as a fraction of thermal-noise RMS, averaged over the original visibility vector. Defaults to 0.1; see select_foreground_rank for the precise criterion.

    		 0.1
    tile_size int

    Positive JAXMG square tile width, default 128. Unused on CPU.

    		 128

    Returns:

    Type Description
    Path

    Completed complex128 operator, shape (n_visibility, retained_rank), ready for joint assembly with a standard-normal foreground prior.
    Notes

    On CPU, native JAX computes an unpadded, thin SVD on one device in one process. The input, thin singular-vector matrices and solver workspace must fit in local RAM. This path requires neither CUDA nor JAXMG.

    On GPU, every process calls together, with one GPU per process and shared storage. Only local shards are read from disk; zero padding permits the distributed JAXMG GESVD. Full U is never gathered, and Vh is not computed. This is a dense SVD: the input, U and solver workspace must fit the allocated GPUs. Padding is excluded from the output and the RMS normalisation.

    This function always computes its requested product, independently of setup and cache policy. It neither constructs A nor changes the inference prior. Existing outputs are replaced only after successful computation. The JAX backend selects the implementation; a GPU solver failure does not trigger a CPU fallback. Neither path uses approximate/randomised decomposition.

    bayeseor_jax.model.construction.kl_reduction.select_foreground_rank ¶

    select_foreground_rank(singular_values, n_vis, f=0.1)

    Find the smallest rank meeting the discarded prior-predictive RMS limit.

    Parameters:

    Name Type Description Default
    singular_values array - like

    Non-negative singular values of A = N^-1/2 T_fg Sigma_q^1/2, ordered from largest to smallest, with modes introduced by padding excluded.

    		 required
    n_vis int

    Number of measured complex visibilities, before solver padding.

    		 required
    f float

    Maximum discarded RMS relative to thermal-noise RMS; defaults to 0.1. Zero retains every mode with a nonzero computed singular value.

    		 0.1

    Returns:

    Name Type Description
    rank int

    Smallest retained dimension satisfying the criterion, possibly zero.
    tail_rms ndarray

    Discarded RMS for every rank, including the zero tail at full rank.
    Notes

    The criterion is epsilon(r) = sqrt(sum(s[r:]**2) / n_vis) <= f. This is an average in noise-whitened visibility space, not a bound on each sample or on each realisation. The foreground prior is not applied a second time.

    Likelihood products¶

    The fixed products of the marginalised likelihood, \(\mathbf T^\dagger\mathbf N^{-1}\mathbf T\), \(\mathbf T^\dagger\mathbf N^{-1}\boldsymbol d\) and \(\boldsymbol d^\dagger\mathbf N^{-1}\boldsymbol d\). save_likelihood_products writes all three; the build_ functions evaluate them in memory.

    Prepare likelihood products from an explicitly selected, saved joint operator.

    The physical model and any foreground compression have already been constructed. This module knows only T, the inverse-noise diagonal, and the observed data. Pure contractions define the mathematics; save functions handle device sharding and publication. No operator is implicitly built, concatenated or reduced here.
