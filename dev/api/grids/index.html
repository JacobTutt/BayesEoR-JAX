    Sky and Fourier grids¶

    build_image_geometry selects the HEALPix pixels of each model field and tracks their directions through the observation. build_fourier_geometry defines the EoR coefficient grid, whose modes are converted to wavenumbers and grouped into power-spectrum bins.

    Sky pixels¶

    bayeseor_jax.model.observation.image_geometry.required_healpix_nside ¶

    required_healpix_nside(longest_baseline_m: float, highest_frequency_hz: float, *, samples_per_fringe: float = 2.0) -> int

    Estimate the HEALPix resolution needed to sample the shortest fringe.

    Parameters:

    Name Type Description Default
    longest_baseline_m float

    Largest physical baseline length in metres, finite and non-negative. Use the full three-dimensional length, not just its uv projection.

    		 required
    highest_frequency_hz float

    Highest observing frequency in Hz, finite and positive. This sets the shortest wavelength and hence the finest instrumental fringe scale.

    		 required
    samples_per_fringe float

    Number of nominal pixels per fringe, at least two. Defaults to the two-sample Nyquist estimate; larger values provide finer sampling.

    		 2.0

    Returns:

    Type Description
    int

    Smallest power-of-two nside satisfying the nominal pixel-size criterion, with a minimum of one. Values outside the supported HEALPix range (nside < 2**30) raise ValueError.
    Notes

    The largest angular phase gradient is \(2\pi b_{\max}/\lambda\). Using the nominal HEALPix pixel width \(\sqrt{\Omega_{\rm pix}}\) therefore gives

    \[ \frac{\sqrt{\pi/3}}{N_{\rm side}} \leq \frac{c}{s\,b_{\max}\nu_{\max}}, \]

    where \(s\) is samples_per_fringe. For a zero baseline there is no fringe-resolution requirement and the function returns one.

    This is a baseline-based sampling estimate, not a strict spherical sampling theorem: HEALPix pixels have different shapes, and beam, sky structure and sharp horizon masks can require finer quadrature. Check visibility convergence at higher resolution when accuracy matters. The helper does not change a run's configured resolution or foreground prior. See https://healpy.readthedocs.io/en/latest/generated/healpy.pixelfunc.nside2resol.html for the nominal pixel-width convention.

    Fourier grid¶

    bayeseor_jax.model.cosmology.fourier_geometry.build_fourier_geometry ¶

    build_fourier_geometry(*, n_u: int, n_v: int, n_eta: int, du: float, dv: float, d_eta: float) -> FourierGeometry

    Define the rectilinear Fourier grid of the cosmological 21-cm brightness field.

    Parameters:

    Name Type Description Default
    n_u int

    Number of transverse u modes before removing the angular monopole.

    		 required
    n_v int

    Number of transverse v modes before removing the angular monopole.

    		 required
    n_eta int

    Number of line-of-sight Fourier modes before excluding eta=0.

    		 required
    du float

    Transverse u spacing in inverse radians; must be positive.

    		 required
    dv float

    Transverse v spacing in inverse radians; must be positive.

    		 required
    d_eta float

    Positive eta spacing and integration weight in inverse Hz (seconds).

    		 required

    Returns:

    Name Type Description
    geometry FourierGeometry

    Retained coordinates and spacings for (n_un_v - 1)(n_eta - 1) coefficients.
    Notes

    The intrinsic cosmological brightness field is parameterised by complex amplitudes on a three-dimensional rectilinear (u, v, eta) grid, rather than by independent image-pixel amplitudes. The transverse coordinates u and v are Fourier duals of the reference-time image direction cosines (l, m), while eta is the Fourier dual of observing frequency. These are model coordinates, not the baselines sampled by the instrument. The transverse representation uses a local tangent-plane description of the cosmological field.

    This basis provides a natural parameterisation for power-spectrum inference. At a reference redshift, the modes map to comoving wavenumbers as

    \[ k_x = 2\pi u / D_M, \qquad k_y = 2\pi v / D_M, \qquad k_z = 2\pi\eta / |d\chi/d\nu|. \]

    Here D_M is the transverse comoving distance and |dchi/dnu| is the line-of-sight distance per unit frequency. Under the statistically homogeneous and isotropic Gaussian signal model, distinct Fourier modes are uncorrelated and their prior variances are determined by the power spectrum at |k|. Grouping modes into spherical k bins therefore links the coefficient prior directly to the power-spectrum amplitudes inferred downstream, while the individual amplitudes can be analytically marginalised. Coordinate conversion, binning, and prior construction are separate from this geometry builder.

    Every retained transverse pair is combined with every retained eta mode. The (u, v)=(0, 0) pair and eta=0 plane are excluded, leaving (n_u*n_v - 1) * (n_eta - 1) coefficients. Flattening orders v first, then u, with eta varying fastest. The spacings du, dv, and d_eta also supply the Fourier integration weights; they are normally chosen from the reciprocal transverse model extents and observing bandwidth.

    Downstream, F_z maps eta modes to frequency and F' maps transverse modes to brightness at the selected HEALPix pixel centres. The primary beam and full three-dimensional fringe response then propagate this field into the measured visibilities, where instrumental coupling mixes the mode signatures. This function defines only coordinates and spacings; it does not construct a brightness realisation, prior covariance, or any of those operators.

    generate_k_modes_in_physical_coordinates(uv: Array, eta: Array, transverse_distance_mpc: float, line_of_sight_distance_mpc_per_hz: float) -> jax.Array

    Convert retained instrumental Fourier modes to cosmological wavenumbers.

    Parameters:

    Name Type Description Default
    uv Array

    Transverse angular Fourier coordinates, shape (2, n_uv_mode), in inverse radians; these are model modes, not sampled baselines.

    		 required
    eta Array

    Line-of-sight Fourier coordinates, shape (n_eta_mode,), in inverse Hz.

    		 required
    transverse_distance_mpc float

    Transverse comoving distance D_M at the reference redshift, in Mpc.

    		 required
    line_of_sight_distance_mpc_per_hz float

    Positive conversion factor |dchi/df| at that redshift, in Mpc/Hz.

    		 required

    Returns:

    Name Type Description
    mod_k Array

    Wavenumber magnitudes in inverse Mpc, shape (n_uv_mode*n_eta_mode,), with eta varying fastest to match the cosmological operator columns.
    Notes

    The conversion is (k_x, k_y) = 2*pi*(u, v)/D_M and k_z = 2*pi*eta/|dchi/df|. Each Cartesian combination receives a spherical magnitude used to assign its power-spectrum prior bin.
