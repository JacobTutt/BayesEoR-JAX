# Tests

The test suite mirrors the package: each module `bayeseor_jax/<path>/<name>.py`
has its tests in `tests/<path>/test_<name>.py`. End-to-end runs of small
configurations are in `tests/end_to_end/`.

```bash
python -m pytest                  # everything that can run here
python -m pytest -m "not slow"    # skip the slower end-to-end runs
python -m pytest tests/model      # one part of the package
```

Tests that need MultiNest (`@pytest.mark.multinest`) or two or more GPUs
(`@pytest.mark.gpu`) are skipped automatically when these are unavailable.

## Fixtures

`tests/fixtures/` holds a small committed dataset, regenerated by
`python tests/fixtures/make_fixtures.py`:

- `tiny.uvh5`: a four-antenna, four-channel, four-integration drift scan at the
  HERA site, in Jy, with autocorrelations and XX/YY polarisations.
- `tiny_npy/`: the same observation preprocessed into a `.npy` data vector and
  instrument model.
- `airy_efield.beamfits`: a coarse Airy electric-field beam covering the band.

Shared pytest fixtures, including `tiny_config` for small `RunConfig` objects,
are defined in `tests/conftest.py`.

## Conventions

- Every test has a one-line docstring stating the property it checks.
- Tests for one function are grouped in a `Test<FunctionName>` class.
- Results are checked against independent references where possible, such as a
  brute-force NumPy sum or a dense Gaussian density, rather than by re-running the
  same code.
- Cases are parametrised rather than looped; random inputs use the seeded `rng`
  fixture; files are written only under `tmp_path`.
- Each test takes well under a second where possible; tests over a few seconds
  are marked `@pytest.mark.slow`.
